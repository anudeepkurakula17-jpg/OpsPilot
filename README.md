OpsPilot – Multi-PDF RAG Chat Assistant
OpsPilot is an AI-powered Retrieval-Augmented Generation (RAG) application that allows users to upload multiple PDF documents and ask questions based on their contents. The system retrieves relevant information from the uploaded documents using vector embeddings and generates accurate responses using a Large Language Model (LLM).

Features
Upload multiple PDF documents
Extract text from PDFs
Automatic text chunking
Vector embeddings using Google Gemini
ChromaDB vector database
Semantic document retrieval
AI-powered answers using Groq LLM
Conversation memory
FastAPI backend
React frontend
Modern and responsive UI
